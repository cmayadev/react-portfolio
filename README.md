# react-portfolio

Portfolio personal de [Cristian Maya](https://cmaya.dev), con una estética inspirada en
Visual Studio Code y un modo "escritorio" al estilo Windows 98.

Construido con React (Create React App) y Sass.

## Desarrollo

```
npm install
npm start
```

Abre [http://localhost:3000](http://localhost:3000).

## Build de producción

```
npm run build
```

Genera la carpeta `build/` lista para desplegar.
